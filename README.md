# Papagayo Gastrobar

Papagayo Gastrobar is a modern restaurant and nightlife web experience designed to present the venue, menu, cocktails, social atmosphere, customer reviews, and reservation path in a polished single-site experience.

## Core experience

- Brand and venue storytelling
- Cocktail showcase
- Food/menu presentation
- Tardear / social experience promotion
- Customer reviews
- Reservation experience
- Venue information
- Responsive navigation and landing experience
- Supabase-backed application services

## Site structure

The homepage is composed from dedicated sections for navigation, hero content, marquee messaging, about, cocktails, menu, Tardear, reviews, reservations, venue information, and footer content. This componentized structure makes the experience straightforward to maintain and extend.

## Technology

- Next.js 16
- React 19
- TypeScript
- Tailwind CSS 4
- Supabase
- Vercel-ready configuration

## Development

```bash
npm install
npm run dev
```

Then open `http://localhost:3000`.

Production Supabase credentials and other private configuration should be supplied through environment variables and never committed to source control.
